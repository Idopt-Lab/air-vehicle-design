# Appendix B — Standard Atmosphere

**Source:** Raymer, *Aircraft Design: A Conceptual Approach*, 6th ed. (AIAA, 2018), Appendix B
"Standard Atmosphere," printed pp. 963–968.

Two tables tabulating the 1976 U.S. Standard Atmosphere: Table B.1 in British Imperial
(fps) units, Table B.2 in SI (mks) units. No numbered equations, no figures — pure
atmosphere-property tables. Both give, at each altitude: temperature, pressure, density, speed
of sound, dynamic viscosity, and kinematic viscosity.
