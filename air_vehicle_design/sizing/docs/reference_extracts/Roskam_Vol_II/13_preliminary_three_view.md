# Chapter 13 — The Result of Preliminary Design Sequence I: The Preliminary Threeview

**Source:** Roskam, *Airplane Design, Part II: Preliminary Configuration Design and Integration of
the Propulsion System* (Roskam Aviation / DARcorporation), Chapter 13 "The Result of Preliminary
Design Sequence I: The Preliminary Threeview," printed pp. 295–302.

This chapter is a **result chapter**, not a method chapter. It contains **no numbered equations**.
It closes preliminary design (p.d.) sequence I. It collects the work of Chapters 3 through 12 into
one Class I threeview per example airplane, and one geometry summary table per example airplane.

For a sizing framework the value of this chapter is the **three complete, self-consistent geometry
data sets** in Tables 13.1, 13.2 and 13.3. They are the only place in Part II where a full set of
wing / HT / VT / fuselage geometry inputs is printed together for one airplane. They make good
regression inputs for a Class I geometry module.

---

## §13.0 Purpose of the chapter (p. 295)

The chapter combines the work of Chapters 3 through 12 into a preliminary threeview of the
configuration.

Roskam gives a warning about the status of this drawing:

- The preliminary threeview is also called the **Class I threeview**.
- It is PRELIMINARY. The book prints that word in capitals.
- It holds all the corrections to the configuration that Chapters 3 through 12 made necessary.
- It is the start point for p.d. sequence II. That work starts with **Step 17 in Chapter 2**.

During p.d. sequence II the reader must use more accurate methods. Those methods are the subject of
Parts III through VIII of the series.

The rest of the chapter gives the Class I threeviews for the three example airplanes. The geometric
characteristics of all three are given in tables.

The three example airplanes are the same ones used through Chapters 3 to 12:

| Name | Type | Figure | Table |
|---|---|---|---|
| Selene | twin engine propeller driven airplane | Fig. 13.1, p. 296 | Table 13.1, p. 297 |
| Ourania | jet transport | Fig. 13.2, p. 298 | Table 13.2, p. 299 |
| Eris | fighter | Fig. 13.3, p. 300 | Table 13.3, p. 301 |

## §13.1 Class I Threeview and Geometric Summary for a Twin Engine Propeller Driven Airplane (pp. 295–297)

Figure 13.1 gives the Class I threeview for the Selene. The geometric characteristics are in
Table 13.1.

### Figure 13.1 — Selene: Class I Threeview (p. 296)

Line drawing, printed sideways on the page. Three views: top (plan) view, front view and side view.
No dimensions and no plotted data are printed on the drawing.

What the drawing shows: a low wing airplane with two tractor propeller engines on the wing, a
**V-tail**, a retractable tricycle landing gear with the main gear in the engine nacelles, and a
cabin with four windows on the side. The wing has straight leading and trailing edges with a small
trailing-edge extension inboard.

Notes on Table 13.1:

- `MGC` is the mean geometric chord. `MGC L.E.: F.S.` is the fuselage station of the leading edge of
  the MGC. The F.S. datum is ahead of the nose, so a station can be larger than the overall length.
- The **overall maximum width equals the wing span** (37.1 ft). The same is true in Tables 13.2 and
  13.3. So "Overall maximum width" means wing span, not fuselage width.
- Aspect ratio check: `b²/S` = 37.1²/172 = 8.00 (wing), 14.9²/58 = 3.83 (HT), 6.16²/38 = 1.00 (VT).
  All three agree with the printed aspect ratios.
- The wing airfoil is printed as **NASA(1)-0317** root and **NASA(1)-0313** tip. This is how the book
  prints it. The designation is not a standard NASA or NACA form. Recorded as printed. Do not
  substitute another designation.
- The Selene has a V-tail (see Fig. 13.1), but the table still lists separate horizontal-tail and
  vertical-tail geometry. The table gives the **equivalent** horizontal and vertical surfaces.
- The vertical tail dihedral row reads "not appl." (not applicable) in all three tables.

Notes on Table 13.2:

- **Suspected misprint (p. 299).** The fuselage length prints as `1243 ft` and the overall length as
  `1270 ft`. Both are printed with no decimal point. I rendered this cell at 600 dpi to confirm the
  characters. The intended values are almost certainly **124.3 ft** and **127.0 ft**. The wing MGC
  leading edge is at F.S. 88.8 ft and the horizontal-tail MGC leading edge is at F.S. 124.9 ft, so
  the airplane is about 127 ft long, not 1270 ft. Use 124.3 ft and 127.0 ft, and keep the record that
  the book prints 1243 and 1270.
- Aspect ratio check: 113.8²/1296 = 9.99 (wing), 35.6²/254 = 4.99 (HT), 19.0²/200 = 1.81 (VT).
  All three agree with the printed aspect ratios.
- The fuselage is circular. Maximum height and maximum width are both 13.2 ft.
- The wing flap is in two spanwise segments. The aileron occupies the gap between them (0.23 – 0.34).

## §13.3 Class I Threeview and Geometric Summary for a Fighter (pp. 295, 300–301)

Figure 13.3 gives the Class I threeview for the Eris. The geometric characteristics are in
Table 13.3.

### Figure 13.3 — Eris: Class I Threeview (p. 300)

Line drawing, printed sideways on the page. Three views: top (plan) view, front view and side view.
No dimensions and no plotted data.

What the drawing shows: a **twin boom** fighter. The plan view shows an unswept wing with two booms
that run aft from the wing, and a horizontal tail that spans between the two boom ends. The front
view shows the two vertical tails at the boom ends. They carry the horizontal tail between them,
which makes an H-tail. A short central fuselage or nacelle carries the cockpit and one engine. The
gear is a retractable tricycle gear. Spoiler panels are marked on the wing.

Notes on Table 13.3:

- Table 13.3 has **no "Cabin Interior" column**. Tables 13.1 and 13.2 have one. The fighter has no
  cabin, so the column is not printed.
- The Eris has **no aileron row**. Roll control is by spoiler only. This agrees with Chapter 6, which
  permits spoiler-only roll control when the full wing trailing edge is necessary for flaps. Here the
  flap span ratio is 0.12 – 1.0.
- Aspect ratio check, wing: 68.7²/787 = 6.00. This agrees with the printed value.
- Aspect ratio check, horizontal tail: 18.3²/93 = 3.60. This agrees with the printed value.
- **Internal inconsistency, vertical tail (p. 301).** `b²/S` = 10.3²/147 = **0.72**, but the table
  prints an aspect ratio of **1.2**. The same check succeeds for the Selene (1.00) and for the
  Ourania (1.81), so the Eris row is the odd one. The Eris has **two** vertical tails (Fig. 13.3), so
  147 ft² is most probably the total of both fins. Per fin that gives 73.5 ft² and `b²/S` =
  10.3²/73.5 = 1.44, which still does not give 1.2. The book does not say if the area is per fin or
  total, and it does not say if the aspect ratio is per fin or for the pair. I could not resolve this
  from the printed page. Record the printed numbers and treat the vertical-tail aspect ratio of the
  Eris as unverified.
- The horizontal tail has taper ratio 1.0 and 0 deg. leading-edge sweep. It is a rectangular surface
  that spans between the two booms.
- Overall maximum width 68.7 ft equals the wing span, as in the other two tables.

## Summary for implementation

Chapter 13 gives no equations. It gives three complete Class I geometry data sets. The table below
collects the quantities that each data set defines, so a Class I geometry module can be checked
against them.

| Quantity (wing / HT / VT) | Selene | Ourania | Eris |
|---|---|---|---|
| Area, ft² | 172 / 58 / 38 | 1,296 / 254 / 200 | 787 / 93 / 147 |
| Span, ft | 37.1 / 14.9 / 6.16 | 113.8 / 35.6 / 19.0 | 68.7 / 18.3 / 10.3 |
| MGC, ft | 4.92 / 4.12 / 6.31 | 12.5 / 7.75 / 11.5 | 11.9 / 5.08 / 7.4 |
| MGC L.E. fuselage station, ft | 20.3 / 45.1 / 40.0 | 88.8 / 124.9 / 123.5 | 21.8 / 51.7 / 46.4 |
| Aspect ratio | 8 / 3.85 / 1.0 | 10 / 5 / 1.8 | 6 / 3.6 / 1.2 *(VT unverified)* |
| Sweep, deg | 0 (c/4) / 30 (LE) / 50 (LE) | 35 (c/4) / 35 (LE) / 45 (LE) | 0 (c/4) / 0 (LE) / 45 (LE) |
| Taper ratio | 0.4 / 0.4 / 0.56 | 0.32 / 0.32 / 0.32 | 0.5 / 1.0 / 0.55 |

Rules that the three data sets share. A Class I geometry module can use them as defaults:

| Rule | Evidence |
|---|---|
| Wing sweep is quoted at c/4. Tail sweep is quoted at the L.E. | all three tables |
| Horizontal-tail incidence is "variable" (all-moving or trimmable) | all three tables |
| Vertical-tail incidence is 0 deg. Vertical-tail dihedral is "not applicable" | all three tables |
| Vertical-tail airfoil is NACA 0015 | all three tables |
| Horizontal-tail airfoil is a symmetrical NACA 4-digit section with a thickness equal to the tail t/c | 0012, 0012, 0010 |
| Overall maximum width equals the wing span | all three tables |
| Rudder chord ratio range | 0.22 (fighter) to 0.45 (jet transport) |
| Elevator chord ratio range | 0.30 to 0.32 |
| Aileron chord ratio range | 0.25 (propeller twin) to 0.30 (jet transport) |
| Flap chord ratio range | 0.25 (propeller twin) to 0.30 (jet transport and fighter) |
| Spoiler chord ratio and hinge line | 0.20, hinge at 0.70c (jet transport and fighter) |
